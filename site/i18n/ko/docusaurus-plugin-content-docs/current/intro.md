## 먼저, 색상 모드를 선택하세요

밝은 모드와 어두운 모드 중 어느 쪽을 선호하시나요? 원하시는 쪽을 선택하실 수 있습니다.

## 필요한 것들

이 워크숍을 위해 **준비해야 할 것들**:

- JavaScript가 활성화된 최신 웹 브라우저.
- 수분 보충을 위한 물!
- GitHub 계정 생성
- 무료 Grafana Cloud 계정 생성

:::info
이 워크숍에서는 github codespace와 Grafana cloud를 이용하여 코드를 실행합니다.
:::
