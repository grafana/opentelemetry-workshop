# ようこそ

Grafana Labs による OpenTelemetry 入門ワークショップへようこそ。

準備が整っているか確認しましょう。

## まず最初に、カラーモードを選びましょう

ライトモードとダークモード、どちらで読みたいですか？どちらも選べます。

右上の Light アイコンをクリックして、好みのカラーモードに切り替えてください ⮥

## 必要なもの

このワークショップでは、**次のものを準備してください**：

- JavaScript が有効な、最新の Web ブラウザー
- 水分補給のための飲み物
- GitHub アカウントの作成
- 無料の Grafana Cloud アカウントの作成

:::info
このワークショップでは、コードの実行に github codespace と Grafana cloud を使用します
:::

## 学習内容

このワークショップでは、次の内容を通して OpenTelemetry の基本を学びます：

- ターミナルで実行するシンプルな演習
- Collector の設定と実行
- 各ラボの最後にあるクイズ
- Grafana Cloud で実際に手を動かすハンズオン手順

準備ができたら、下の Next ボタンをクリックして最初のラボへ進んでください。
